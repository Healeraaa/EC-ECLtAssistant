# EC-ECL Recorder

EC-ECL Recorder 是用于电化学与电化学发光实验的 Windows 上位机软件。当前发布版本为 **v1.1.0**。

## 主要功能

- 串口连接及 CV、DPV、CA、GPCI 实验参数配置。
- 电压、电流、ECL 三通道实时曲线。
- CSV 自动记录，可自行选择保存目录。
- 实时接收速率、帧统计、采样计数和峰值统计。
- 实验参数预设保存与加载。
- CSV 后台加载、倍速回放、进度跳转及最近文件列表。
- 十字光标读取数据、两点差值测量、曲线缩放和 PNG 导出。
- 高数据量下的保峰抽样显示，CSV 原始数据不会被抽样。

## 快速使用

1. 连接设备并启动 EC-ECL Recorder。
2. 在“设备与模式”中选择串口、波特率、实验模式、通道和量程。
3. 在“实验参数”中填写当前模式对应的参数。
4. 在“CSV 记录”中选择保存目录，并确认“保存 CSV”已勾选。
5. 单击“连接串口”，然后单击“发送配置”。
6. 实验完成后单击“断开串口”，CSV 缓冲数据会被完整写入文件。

## 曲线设置

- **缓存点数**：每个通道在界面内存中保留的最近数据点数量，上限为 50000。
- **绘图点数**：每个可见通道实际提交给图表的最大点数，默认 4000。降低该值可减少 CPU 占用。
- **暂停曲线刷新**：仅暂停画面刷新，串口接收、统计和 CSV 保存继续运行。
- **自动缩放**：根据当前可见通道自动调整坐标轴。
- **十字光标**：鼠标在图表内移动时显示最近采样值。
- **两点测量**：依次单击 A、B 两点，显示时间差和各通道幅值差。

## CSV 回放

1. 断开串口。
2. 在“CSV 回放”中单击“加载 CSV”。大文件会在后台线程中加载。
3. 使用播放按钮、倍速选项和进度条控制回放。
4. 最近打开的 8 个 CSV 可通过“打开最近文件”重新载入。

回放 100 Hz 的四列原始 GPCI CSV 时，软件会在后台自动生成滤波数据；加载
已经包含滤波列的 CSV 时则直接使用已保存结果。加载完成后文件状态会显示
“滤波可用”，可在“曲线控制”中切换“显示滤波结果”和“显示原始数据”。

“实时状态”会显示有效 ECL 脉冲数量、最近一次滤波积分面积、平均面积和变异
系数（CV）。实时记录停止时，软件会在数据 CSV 同目录自动生成同名
`_pulses.csv`，保存每个脉冲的局部基线、峰值、原始/滤波积分面积及面积偏差。

“滤波质量”会显示最近一个可评价脉冲的信噪比改善、背景噪声下降比例、面积
偏差，以及当前记录中的质量警告数量。质量警告只表示滤波结果可能失真或未能
降低背景噪声，不用于判断实验样品是否异常。默认判定条件为面积绝对偏差超过
5%、滤波后背景噪声增大或信噪比下降。“滤波质量阈值”区域可调整这三个条件，
设置会自动保存；串口连接期间阈值会锁定，避免同一次实验中途改变判定标准。

`_pulses.csv` 保留 `RawArea` 和 `FilteredArea`，并增加 `RawNoiseRMS`、
`FilteredNoiseRMS`、`NoiseReduction(%)`、`SNRImprovement(dB)`、
`AreaDifference(%)`、`QualityEvaluated`、`QualityWarning`、`QualityReason` 和
`Valid`，并逐行记录本次使用的三个质量阈值。如果停止记录时一个脉冲尚未结束，
该脉冲会作为 `InvalidPulse` 写入汇总，
不会混入有效面积的平均值和 CV。

支持的表头格式：

```csv
Time(s),Voltage(V),Current(A),OpticalSignal
```

## 实验预设

“保存预设”会将模式、参数、通道、量程及曲线设置保存为 JSON。“加载预设”只更新上位机界面参数，不会自动向设备发送配置。

## GPCI 滤波原型

项目包含独立的 `SignalFilterPipeline`，用于验证 100 Hz GPCI 数据的脉冲感知
`sym4` 小波与卡尔曼滤波。滤波只作用于上位机数据，不修改 MCU、串口协议或原始采样列。

- 默认使用 128 点窗口和 64 点步进，对应 0.64 秒结果延迟。
- GPCI 脉冲及电流恢复区会自动降低滤波强度，避免削弱短脉冲。
- ECL 结果以局部基线扣除后的脉冲积分面积作为主要保真指标。
- 离线工具输出保留原始四列，并追加滤波列、有效标记和 GPCI 事件标记。
- 脉冲汇总文件包含原始/滤波峰值、积分面积和面积变化率。

离线原型工具的命令格式：

```text
FilterCsvPrototype.exe input.csv filtered.csv pulses.csv
```

实时采集时，GPCI 模式可启用滤波并在“曲线控制”中切换显示滤波结果或
原始数据。滤波结果按 64 点一批更新，显示延迟不超过约 0.64 秒；首批 64 点
作为滤波预热区并通过 `FilterValid=0` 标记。启用滤波的 GPCI 记录会在原始四列之后追加三个
滤波列、`FilterValid` 和 `GPCIEvent`，断开串口时会刷新尚未输出的尾部样点。

## 运行环境

- Windows 10/11 x64
- 便携版已包含所需 Qt 运行库和 Microsoft C++ 运行库，无需单独安装 Qt。

## 从源码编译

- Visual Studio 2022，平台工具集 v143
- Qt 5.14.2 MSVC 2017 64-bit
- 构建平台：x64

使用 Visual Studio 打开 `SerialPortAssistant.sln`，选择 Debug 或 Release 构建即可。

## 生成便携版

在 PowerShell 中从仓库根目录执行：

```powershell
.\deploy_release.ps1
```

生成内容位于 `dist` 目录，包括便携版文件夹和 ZIP 压缩包。

## 注意事项

- 本软件不会修改 MCU 固件。
- “清空曲线”只清理界面数据，不会重置设备端实验状态。
- 正式实验前请先进行短时间采集，确认通道、量程和保存目录正确。
